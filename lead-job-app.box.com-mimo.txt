[CONFIRMED] cloud.app.box.com OAuth2 SPA shell CORS origin reflection
class: MISCONFIG
asset: cloud.app.box.com/api/oauth2/authorize (and all /api/oauth2/authorize/* subpaths)
confidence: 85
reasoning: cloud.app.box.com/api/oauth2/authorize reflects arbitrary Origin in `access-control-allow-origin` on the SPA shell response. The response embeds `Box.config` containing: `runtimeMetadata` (availabilityZone: us-west4-prod, deploymentType: k8s, environment: prod), `pendoAnalyticsAPIKey`, `amplitudeAPIKey`, `splitIOAPIKey`, `billing.creditCardCreationURL` (Zuora), `pendoAnalyticsProxyContentHost` (pendo-prod.box.com), `pendoAnalyticsProxyDataHost` (pendo-data-prod.box.com), feature flag map, full webpack remotes manifest (24 modules with versions), preview.version 3.79.0. Additionally embeds `Box.prefetchedData["/app-api/enduserapp/current-user"]` containing the same anonymous user context. Preflight (OPTIONS) allows `Authorization` header and `GET` method. `access-control-expose-headers: WWW-Authenticate,Server-Authorization` exposes auth headers cross-origin. No `access-control-allow-credentials` header present — cookies cannot be sent cross-origin. This is the 4th subdomain with identical behavior (cloud.account.box.com, account.box.com already confirmed).
verify_steps: GET https://cloud.app.box.com/api/oauth2/authorize?response_type=code with Origin: https://evil.com — confirms access-control-allow-origin: https://evil.com and Box.config JSON. OPTIONS preflight confirms Authorization header allowed.
impact: LOW-MEDIUM. Infrastructure metadata (k8s zone, deployment type, feature flags, proxy hostnames, billing endpoints, client-side API keys, webpack manifest) readable cross-origin from any evil.com page. Without ACA, cookie-bearing requests blocked. RuntimeMetadata (us-west4-prod, k8s) NOT in public bundles — reveals infrastructure details useful for targeted attacks. Client-side API keys (pendoAnalyticsAPIKey, amplitudeAPIKey, splitIOAPIKey) already present in public JS bundles but accessible as structured JSON without JS parsing from unauthenticated context.
testability: PASSIVE
