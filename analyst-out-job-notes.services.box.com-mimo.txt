**class:** MISCONFIG  
**asset:** upload.box.com/api/2.0/{files/content, files/upload_session, folders, collaborations, tasks, shared_items}  
**confidence:** 95  
**reasoning:** 
- OPTIONS preflight reflects any Origin (including `null` and `box.com.evil.com`) with `credentials: true` and `Allow-Methods: POST`
- Only POST collection endpoints are affected; GET/PUT/DELETE return no CORS headers
- Subdomain prefix trick works: `box.com.evil.com` accepted as valid Origin
- POST response itself does NOT include CORS headers (blind CSRF only)
